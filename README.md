# 雲林健康好食

以餐點為主的雲林縣 115 年輔導健康商家搜尋網站。48 道不重複餐點、51 筆餐點供應紀錄、44 家店、20 個鄉鎮市。

## 使用

選擇餐點分類、輸入關鍵字，再搭配減糖／減鹽／符合飲食建議、鄉鎮及距離篩選。相同名稱的餐點合併顯示。允許定位後，每道餐點優先顯示符合篩選條件且距離最近的供應店家；詳細視窗按距離列出其他供應店家。距離是直線估算。

網站：https://yht5582-source.github.io/healthstore/

## 資料與查核

- 來源：使用者提供的 `115YH02850_1_11113035454.pdf`，標題「115年輔導健康商家資料」。保留全部餐點與餐點層級健康元素。
- `data.json` 是可閱讀的資料；`data.js` 是相同資料的瀏覽器版本。編輯資料後執行 `node sync-data.cjs` 同步。
- 2026-09-18 逐家使用 Google Maps 核對名稱、門牌及電話，42 家有已核對店家座標。資料內有各店地圖連結、原始地址與電話、地圖顯示地址與電話、查核日期及差異說明。
- 北港「恩典手工餅乾坊」與元長「ㄚ好嬸 古早味紅茶冰」只確認門牌，未確認同名商家；`lat/lng` 留空，不列入半徑篩選。未設定半徑時仍可查到資料，定位排序時列在已確認店家之後並標示距離待確認。
- 土庫玉津咖啡採 Google Maps 的中正路230號，保留 PDF 原地址中山路124號及差異說明。電話吻合。
- 劍湖山渡假大飯店補齊永光村大湖口67之8號，地址來源為[雲林縣旅遊網](https://tour.yunlin.gov.tw/mainssl/modules/MySpace/BlogInfo.php?xmlid=1037016)，位置由 Google Maps 核對。
- 曉明牛肉麵的 Google Maps 名稱是「東勢牛肉麵／燴飯」，門牌與電話一致。
- 不將減糖、減鹽標示擴張至店內其他餐點，不推算營養數值、價格或營業中狀態。

## 部署

純靜態網站，無需金鑰或建置工具。GitHub Pages 設定：Deploy from a branch → `main` → `/ (root)`。`.nojekyll` 關閉 Jekyll 處理。

本地预覽：`python -m http.server 8765`。正式定位需 HTTPS；localhost 也可測試。

## 維護與測試

`node test.cjs` 驗證資料完整性、餐點合併、跨分店最近排序、半徑與鄉鎮篩選、餐點健康標示、缺少座標及空結果。

定位只保存在當次頁面記憶體，無分析追蹤、無定位資料上傳、無 localStorage。地圖與導航按鈕開啟 Google Maps，電話按鈕使用 `tel:`。網站無第三方 JavaScript 或 CSS 依賴。
